## Digital Lamp Control

A basic Siemens HMI–PLC project demonstrating **digital lamp control using an ON/OFF switch**. The HMI provides an operator interface to control a digital output connected to a lamp through the PLC. The project demonstrates fundamental concepts of **digital input/output, HMI switches, PLC tags, and real-time status visualization**.

The lamp can be switched **ON or OFF** from the HMI, with the displayed lamp status synchronized with the corresponding PLC digital output. This project provides a simple foundation for developing more advanced industrial control and HMI applications.

A short demonstration of the Siemens HMI **Digital Lamp Control** project, showing the ON/OFF operation of the lamp through the HMI interface and the corresponding PLC output response.
