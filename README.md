# Siemens HMI – PLC-Based Industrial Automation Project

This repository contains a practical **Siemens Human Machine Interface (HMI)** project focused on industrial automation, PLC communication, process visualization, and alarm management. The project demonstrates the development of an HMI application integrated with a **Siemens S7-1200 PLC**, covering the complete workflow from initial HMI configuration and screen design to PLC communication, process monitoring, and alarm handling.

The project is developed using **Siemens TIA Portal** and is structured around fundamental HMI concepts commonly used in industrial control systems. It includes both simulation-based development using **PLCSIM** and communication with a physical S7-1200 PLC, providing a practical understanding of HMI–PLC integration.

### Key Features

* Siemens HMI project development using **TIA Portal**



* Design of standard HMI forms and process screens
* Interactive **buttons and switches**
* **I/O field** configuration and management
* Real-time process-variable visualization
* Water supply system visualization and control
* Analog-value monitoring and representation
* **Analog alarm** configuration
* Alarm color and status visualization
* Alarm buffer configuration and usage
* Alarm logging and historical alarm monitoring
* Use of graphical symbols and SVG-based industrial elements

### Project Structure

The repository is intended to provide a reproducible reference for understanding how a PLC-controlled process can be represented and operated through an HMI. The water supply system serves as a practical example for implementing digital and analog signals, operator controls, process visualization, and alarm functionality.

The project can be used as a learning resource for students, researchers, automation engineers, and robotics researchers working with **PLC-based automation, industrial control systems, SCADA/HMI interfaces, and cyber-physical systems**.
